## 🛠️ What Does Argyph Do?

When you work with AI coding assistants, they often lack specific details about your current project. Argyph solves this by acting as a bridge. It reads your code files, builds a map of your project, and provides quick answers to AI agents. 

- **Private:** All data stays on your machine.
- **Fast:** It finds specific lines of code in seconds.
- **Simple:** It does not require complex setup or configuration.
- **Smart:** It understands code structure through advanced parsing.

Once you finish the installation, you need to point Argyph at your code.

## 🛡️ Privacy and Security

You own your data. Argyph runs directly on your computer hardware. It never sends your source code to external servers, cloud providers, or third-party databases. The indexes created by the software remain within the local storage of your directory. You can delete these files at any time through the application settings menu.

## 🚀 Troubleshooting Common Issues

If you encounter problems, check the items below:

- **Application fails to start:** Ensure you have the latest version of the Windows operating system.
- **Indexing hangs:** Close other memory-intensive applications and restart the Argyph process.
- **AI cannot see files:** Verify that the folder path in the Argyph settings matches the path you selected. Ensure the "Enable Connection" status is set to active.
- **Search returns no results:** Open the project folder settings and click "Re-index Project" to force a refresh of the file map.

## 📋 System Maintenance

The software performs periodic updates to remain compatible with new versions of AI tools. Open the application once a week to receive automatic updates. If the software seems sluggish, go to the "Storage" tab in settings and select "Clear Cache." This action removes outdated index maps without deleting your actual code files.

## 💡 Tips for Best Performance

For the best experience, keep your folder structure organized. Argyph works fastest when project directories do not contain excessive temporary files or large build artifacts. Use a ".gitignore" file to ensure that the application ignores folders like "node_modules" or "bin." This allows the tool to focus only on the source code that matters to your AI agent. 

The software automatically detects changes in your code. You do not need to restart the application when you save a file. Argyph monitors the directory in the background and updates its internal map in real time. This ensures your AI agent always has access to the most recent changes you make to your work.
